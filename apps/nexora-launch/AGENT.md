# Nexora Launch OS — AGENT.md

## Concept
Launcher/digital operating experience evolving from a lightweight device launcher toward cloud sync, backup, themes, AI, security, cloud services, business capabilities, and eventually platform/SDK/marketplace.

## Instructions
- Keep early versions lightweight and local-first.
- Separate device-local state from cloud sync.
- Treat permissions and device security as first-class concerns.
- Keep cloud capabilities optional to the launcher core.
- Preserve a clear V1/V2/V3 evolution path.
- Optimize for constrained mobile devices.
