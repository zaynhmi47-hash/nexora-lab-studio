# AI Agent Business — AGENT.md

## Concept
Experimental platform for AI agents that execute useful business workflows and automation as monetizable services.

## Instructions
- Every agent action requires explicit tool permissions and auditability.
- Separate planning from execution.
- Require confirmation for high-impact, external, financial, destructive, or irreversible actions.
- Keep tools schema-validated and deterministic where practical.
- Track usage, cost, errors, and outcomes.
- Never allow agents to bypass authorization.
