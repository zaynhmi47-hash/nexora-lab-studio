# Nexora AI — AGENT.md

## Concept
AI workspace for chat, multimodal interaction, files, projects, knowledge bases, agents, tools, research, coding, content generation, voice, automation, and collaboration.

## Instructions
- Treat model providers as replaceable infrastructure.
- Route model access through a controlled AI gateway.
- Never expose provider secrets in clients.
- Track usage, quotas, costs, permissions, and safety boundaries.
- Separate user data, project knowledge, retrieved context, and model output.
- Agent tools require explicit permissions and auditable actions.
- Do not present unverified AI output as authoritative.
