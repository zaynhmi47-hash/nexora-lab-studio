# Nexora Photo — AGENT.md

## Concept
Image/document utility for compression, resizing, conversion, OCR, image-to-PDF, and document processing.

## Instructions
- Prefer local processing for private files when practical.
- Never upload files silently.
- Preserve originals unless the user explicitly chooses replacement.
- Clearly report format, size, and processing errors.
- Isolate heavy processing from the UI thread.
