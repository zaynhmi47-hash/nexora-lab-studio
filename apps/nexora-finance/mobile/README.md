# Nexora Finance Mobile

Cross-platform Finance client built with Expo Router and React Native.

## Commands

From the repository root:

```bash
pnpm install
pnpm --filter @nexora/nexora-finance-mobile typecheck
pnpm --filter @nexora/nexora-finance-mobile start
```

## Configuration

Copy `.env.example` to `.env` for local configuration. Only public client configuration is allowed in Expo environment variables. Secrets must remain on trusted server infrastructure.
