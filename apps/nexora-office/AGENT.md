# Nexora Office — AGENT.md

## Concept
Productivity/document workspace: documents, spreadsheets, presentations, PDF tools, signatures, OCR, scanning, file management, conversion, compression, AI assistance, cloud files, and settings.

## Instructions
- Build a coherent suite, not unrelated utilities.
- Reuse Nexora Core file/document primitives.
- Support responsive mobile, web, and desktop-oriented layouts.
- Make editing reliable, autosave-safe, and version-aware.
- Treat files as sensitive data; enforce authorization and auditability.
- AI must be explicit, permission-aware, and isolated from document integrity.
- Keep modules independently deployable later.
