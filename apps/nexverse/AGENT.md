# Nexverse — AGENT.md

## Concept
Digital library and creator-content platform for books, PDFs, novels, video, music, articles, and educational media, with premium access, advertising, chapter monetization, and creator royalties.

## Instructions
- Separate content ownership, publishing rights, access entitlements, and analytics.
- Protect creator and user data.
- Model premium/chapter access explicitly.
- Royalty calculations must be deterministic, auditable, and versioned.
- Use secure signed access for protected content.
- Keep moderation, copyright, reporting, and takedown workflows extensible.
